## Lumen Capture

| Topic | Finding |
|---|---|
| Stack | Native C++17 Win32 app: Direct2D/DirectWrite UI (own immediate-mode toolkit), DXGI Desktop Duplication + Windows.Graphics.Capture, Media Foundation (H.264/HEVC, AAC), WASAPI, D3D11 compositor. Vendored whisper.cpp (MIT) and RNNoise (BSD). CMake (MSVC) and a MinGW-w64 cross-build script. |
| Version | **2.8.0** (`CMakeLists.txt`, `res/app.rc`, installer, `common.h` agree). README headline still says "1.8" — stale title only. |
| Status | Feature-rich and actively developed (roadmap rounds 0.2–1.0 done; 1.1–2.8 changelog). 2.6 notes "fixes from real-hardware testing". **Not released**: GitHub has **no releases and no tags**. |
| Functionality (documented) | Screen/window/region recording with system audio, 2 mics, camera layouts and scenes, green screen, background blur, instant replay; built-in non-destructive editor (cuts, zoom, annotations, overlays, speed, silence removal, captions); export MP4/GIF/M4A/WAV incl. fast (no re-encode); RTMP/RTMPS streaming; local Whisper captions and RNNoise; plugins + automation pipe; 6 languages; MSAA screen-reader support, high contrast, keyboard navigation. |
| Tests | **No automated test suite** in the repository. CI (`.github/workflows/build.yml`) builds MSVC + installer and MinGW on every push; the last `main` run (2.8.0) passed. |
| Screenshots | `docs/screenshots/*` (Swedish/English mix) and `website/assets/*-en.webp` (English, version **2.5**). README states they are rendered **under Wine on Linux with a fallback font**. New 2.8.0 captures were made in this session the same way (200 % scaling). |
| Icons | `res/app.ico`, `res/rec.ico`, `res/icon-256.png` (generated by `tools/make_icons.py`). |
| About / Settings / splash | About & help page (F1) with an "About Lumen Capture" card (logo, version, "Made by Jimmy Eliasson", copyright) and a built-in PDF manual. Settings page with theme (System/Dark/Light), language, etc. **No splash screen.** |
| Installer & distribution | Inno Setup installer built in CI (artifact only) + per-user self-install. **Not code-signed** (README: MSIX would need a trusted certificate). Publisher in metadata: "Jimmy Eliasson". The in-app updater reads the latest GitHub release — **the repository is private and has no releases**, so public updates cannot work as-is. |
| Own website | `website/index.html` (bilingual) says "Download for Windows" and "Version 2.5" — **outdated and misleading while nothing is published**; not reused on taren.se. |

### Release blockers (Lumen Capture)
1. No public release/download; repository private → updater cannot reach releases.
2. Installer and exe not code-signed (SmartScreen warnings expected).
3. No automated tests; verification is CI build + manual/Wine checks.
4. Screenshots are Wine renders; real Windows captures (Segoe UI) recommended before publishing.
5. Owner approval to publish the taren.se product page (currently `published: false`).
6. Own `website/` copy references a download and version 2.5.
