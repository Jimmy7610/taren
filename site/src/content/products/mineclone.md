MineClone is a browser-based survival sandbox inspired by block-building games.
Explore a procedurally generated world, gather materials, craft tools and build a home.
Choose survival mode or relaxed builder mode.

The solo game runs in the browser without installation. Saves are local to the browser,
so export important worlds before clearing browser data or switching devices.

Multiplayer is optional and depends on a compatible game server being available.
MineClone is an independent game, not affiliated with Minecraft, Mojang or Microsoft.

**A Taren Game.** Developed as an independent, AI-assisted project.
